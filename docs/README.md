# Team website (GitHub Pages)

This folder is the team website. GitHub builds it automatically every time
something is merged into `main` (Settings → Pages → `main` / `/docs`).
It usually updates within a couple of minutes.

- **Pages** (top menu): `robot.md`, `attachments.md`, `code.md`,
  `innovation.md`, `sources.md`, `team.md` — plain Markdown, edit them like
  any text file.
- **Blog posts:** `_posts/YYYY-MM-DD-title.md`. Start from
  `_drafts/post-template.md`. Topic list: `BLOG_IDEAS.md`.
- **Photos:** `assets/images/`. Resize to about 1600 px wide before adding
  (phone photos are huge). `.jpg` or `.png`, not `.HEIC`.
- **Yellow boxes** on the site are reminders of things to fill in — delete
  each box when it's done.

## Safety rules for a public site (coaches, please enforce)
- First names only. No last names, school, town details, or emails.
- Get parent permission before posting any photo that shows a team member's face.
  Photos of the robot, attachments, and hands are always fine.
- Coaches review every post before it's merged into `main`.
- Check with experts before naming them online.
