# Experiments

Everyone's practice and test programs, saved from Pybricks Code backups
(October 18, November 3, and November 18, 2026). Many started as Pybricks **blocks**
programs — the long `# pybricks blocks file:` line at the top is the blocks
layout, and the Python below it is what the blocks turned into.

These aren't used in competition. They're here because they show how the
whole team learned to code this season (driving lessons, controller tests,
line alignment, first versions of each mission). Add new experiments in a
dated folder.
